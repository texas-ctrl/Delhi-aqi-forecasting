# Delhi AQI Forecasting

This project studies Delhi’s hourly AQI from 2018 to 2025 using CPCB city-level AQI workbooks and hourly pollutant/weather readings from six Delhi monitoring stations. The current work is data exploration and EDA; model training has not started.

## Current research question

The EDA is preparing a daily forecast issued at 4 PM: will Delhi’s city AQI be at least 301 exactly 24, 48, or 72 hours later? The primary candidate label is the exact +48-hour value, with starting AQI below 301. Secondary labels record whether either the +24-hour or +48-hour endpoint reaches 301, and whether any hourly AQI in the next 48 hours reaches 301. These are exploratory targets; modeling has not started. Planned comparisons are literal persistence, AQI-only risk, AQI plus winter timing, and later weather/pollutant models. Validation is small, and the 2024–25 test winter stays untouched until model and alert-threshold choices are made.

## Data

- **AQI target:** hourly CPCB city-level workbook series for all years 2018–2025. Original values are preserved in the processed source CSV.
- **2021 review status:** a six-station PM-derived AQI comparison reports that January–September 2021 workbook values need review, while October–December are consistent with the proxy; December 20 also matches the CPCB bulletin exactly. Notebook 01 marks these months without editing their values. Notebook 02 masks January–September AQI only in its analysis copy.
- **Station measurements:** hourly CSV files in `raw_data/` for Anand Vihar, Rohini, RK Puram, Punjabi Bagh, ITO, and Okhla (2018–2025).
- **Processed data and figures:** generated by the notebooks and saved under `processed_data/` and `eda_plots/`.

## Winter study and splits

The primary winter analysis excludes **winter 2020** (November 2020–February 2021), because January–February 2021 AQI is under review. It retains winter 2021–22: November–December 2021 are cross-check consistent, and January–February 2022 use the regular city-level source. Training uses winter-start years 2018, 2019, 2021, and 2022; validation uses 2023; testing uses winter 2024–25. No model is trained yet.

The PM-derived series is a proxy and is not substituted for official city AQI. Any repaired Jan–Feb 2021 target would need its own reproducible calculation and multiple CPCB bulletin spot checks first. See [2021 source notes](aqi_target/2021/README.md).

Run the notebooks in order with the Jupyter working directory set to the `notebooks/` folder. Their relative paths use `../` to reach the repository folders. Install packages from `requirements.txt` and select that Python environment as the Jupyter kernel.

## Current findings and limitations

- AQI has strong correlations with PM2.5 and PM10; these are associations, not evidence of cause.
- AQI is persistent from one hour to the next, so future model evaluation must compare against persistence.
- The winter event count is small, especially in the held-out 2024–25 winter. Report event-level results with uncertainty, not AUC alone.
- 2020 was an unusual COVID-affected year; CAQM also reported restrictions for a considerable period in 2021. This is context for interpretation, not by itself a reason to discard a year. [CAQM annual comparison](https://www.pib.gov.in/Pressreleaseshare.aspx?PRID=1888090&lang=2&reg=48)
