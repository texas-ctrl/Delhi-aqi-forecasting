# Delhi AQI Forecasting

This project studies Delhi's **hourly AQI** from 2018 to 2025 using official city-level AQI workbooks and hourly measurements from six CPCB monitoring stations. The current work is data exploration, EDA, and research planning. Model training has not started.

## Current research question

The project is exploring whether Delhi can have a large AQI increase over a 48- or 72-hour horizon. The current notebook label checks AQI at the exact future timestamp: AQI is at most 250 at the starting hour and at least 301 exactly 48 or 72 hours later. Whether the eventual research question should instead count any crossing within the forecast window is still to be decided.

## Data

- **AQI target:** hourly CPCB city-level Excel workbooks in `aqi_target/` (2018–2025), except 2021, which is reconstructed from 39 CPCB station AQI files.
- **Station measurements:** hourly CSV files in `raw_data/` for Anand Vihar, Rohini, RK Puram, Punjabi Bagh, ITO, and Okhla (2018–2025).
- **Processed data and figures:** generated by the notebooks and saved under `processed_data/` and `eda_plots/`.

The repository includes three processed CSV snapshots: `delhi_6station_avg_2018_2025.csv` (full hourly dataset), `delhi_6station_avg_2018_2025_cleaned.csv` (cleaned feature version), and `anand_vihar_2025_merged.csv` (a separate Anand Vihar 2025 intermediate, not used as input to the full-period notebooks). The raw and processed data folders are intentionally tracked so the notebooks can be rerun from a fresh clone.

### 2021 AQI source

The original 2021 city-level workbooks are retained for reference, but the notebook uses a reconstruction made by averaging the hourly AQI values reported by 39 CPCB Delhi stations. The station CSVs and the reproducible builder `src/build_2021_aqi.py` are in the repository. Of 8,760 hours, 8,741 have at least one station value; the remaining 19 hours stay missing. The processed data includes an `AQI_source` column to distinguish `official_city_level` from `reconstructed_station_mean` rows. The local 2021 annual mean of daily values is about 211, compared with CAQM's published 209. Some individual month means differ by 8–12 points; this compares our hourly station average with CAQM's published daily city figures. The CAQM [2023 annual perspective table](https://www.pib.gov.in/PressReleasePage.aspx?PRID=1991970&lang=2&reg=3) reports May 2021 as 144. Annual AQI values for 2024–2025 and good-to-satisfactory day counts through 2025 come from the later [2025 CAQM annual perspective table](https://www.pib.gov.in/PressReleasePage.aspx?PRID=2210305&lang=1&reg=1).

The local February 2018 daily mean is about 261, compared with CAQM's published 243. A separate station aggregate is about 270, so it does not resolve the difference. February 2018 remains unchanged and is flagged for source review; it is outside the complete winters used in the model-ready split.

The source files include missing readings and incomplete periods. The notebooks keep these gaps visible; the processed data should not be interpreted as a complete record at every timestamp.

## Notebooks

1. `notebooks/01_explore_data.ipynb` — loads and combines the source data, explores coverage, and creates the processed hourly table.
2. `notebooks/02_eda_data.ipynb` — explores trends, missingness, pollutant relationships, lags, seasonal behavior, and the candidate event labels.

Run the notebooks in order with the Jupyter working directory set to the `notebooks/` folder. Their relative paths use `../` to reach the repository folders. Install the packages in `requirements.txt` and select that Python environment as the Jupyter kernel. No model is trained by these two notebooks.

## Current findings and open decisions

- AQI has strong correlations with PM2.5 and PM10 in the current hourly data; these are associations, not evidence of cause.
- AQI values are highly persistent from one hour to the next. The source's hourly AQI calculation and smoothing need further investigation.
- The candidate event is uncommon, especially outside winter. Evaluation will need to account for class imbalance.
- Before modeling, audit timestamp and station coverage, resolve the exact-hour versus any-time event definition, correct the wind-speed interpretation in the EDA notes, and finish the literature review.
